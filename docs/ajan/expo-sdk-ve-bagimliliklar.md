# Expo SDK yükseltmesi ve bağımlılıklar

Ne zaman okunur: bağımlılık ekler/yükseltirken, lockfile üretirken, `npm audit` bulgusunda ya da Expo SDK yükseltirken.

## Lockfile ve kurulum
- **Lockfile'ı CI'nin npm'iyle üret: `npx -y npm@10 install`, sonra `npx -y npm@10 ci` ile doğrula** (CI'nin tam komutu; exit 0 = senkron). npm 11 (Node 24) bazı transitifleri lockfile'dan düşürür (yaşandı: `cosmiconfig@9.0.2`); CI `Missing: <paket> from lock file` ile patlar, master kırmızı, auto-release atlanır. `npm run verify` yerelde yine GEÇER (mevcut `node_modules`, `npm ci` bütünlük denetimi yok) — yanıltıcı. Birleştirilen dependabot lockfile'larında özellikle önemli.
- **`package.json` değiştiyse ya da master çekildiyse önce `npm install`;** "modül bulunamadı" kod hatası değil, senkronsuz `node_modules`'tır.

## Güvenlik denetimi (`npm audit`)
- **`npm audit` sayısı ≠ kullanıcı riski; önce bağımlılık yolunu izle.** APK'ya yalnız uygulama kodundan import edilen JS + native kod girer. 2026-07 ölçümü (PR #170): 29 zafiyetin tamamı build/dev zincirindeydi (`ws`←`@react-native/dev-middleware`/`metro`, `undici`←`@expo/cli`, `form-data`←`jsdom`, `fast-uri`/`flatted`←eslint, `lodash`←`commitizen`/`jest-expo`, `uuid`←`xcode`, `tmp`←`patch-package`, `postcss`←`@expo/metro-config`/`tailwindcss`). Ebeveyni `package-lock.json`'ı Node ile tarayarak bul (`npm ls` yavaş/timeout). Kırıcı olmayan `npm audit fix` (npm@10, `--force` YOK) 29→14 indirdi, `package.json`'a dokunmadı.
- **`npm audit fix --dry-run` sonundaki özet düzeltme ÖNCESİdir.** Gerçek etkiyi repoya dokunmadan ölç: `package.json`+`package-lock.json`'u geçici dizine kopyala → `npx -y npm@10 audit fix --package-lock-only` → `npx -y npm@10 audit`.
- **`npm audit fix --omit=dev` dev bağımlılıklarını `node_modules`'tan siler** (typecheck "Cannot find name 'describe'") → ardından `npm install`.

## Build doğrulaması
- **Bağımlılık değişikliğinin build'i kırıp kırmadığını `npm run verify` GÖSTERMEZ.** `@expo/cli`, `@expo/metro-config`, `@expo/config-plugins` yalnız APK üretiminde çalışır. Dala push et + `gh workflow run android-build.yml --ref <dal> -f build_type=debug`; debug APK yeşilse araç zinciri sağlam. Release'i master'da körlemesine deneme.
- **NDK'sız yerel Android doğrulaması:** `./gradlew :app:testDebugUnitTest -PreactNativeArchitectures=x86_64 --max-workers=2` uygulamanın ve tüm kütüphane modüllerinin Kotlin/Java derlemesini + KSP'yi (AppFunctions şeması) + JVM testlerini koşar, C++/CMake derlemez (SDK 57'de ~7 dk). Maven Central 429 verirse depoya girmeyen bir `--init-script` ile `repo.maven.apache.org`'u `https://maven-central.storage-download.googleapis.com/maven2/` aynasına çevir ve aynayı `pluginManagement` depolarının başına koy.

## patch-package / nativewind
- **nativewind bump'ı = yama adı bump'ı.** `patches/react-native-css-interop+<surum>.patch` nativewind'in transitif `react-native-css-interop` sürümüne bağlıdır (bugün nativewind 4.2.7 → `react-native-css-interop+0.2.7.patch`). Ad eskiyince yama yine uygulanır ama her kurulumda "version mismatch" uyarısı çıkar → `npx patch-package react-native-css-interop` ile yeni adla yeniden üret, eskisini sil. Yama hiç uygulanmazsa `.cache/*.js` (boş dosyalar) ve `render-component.js`'teki `stringify` try/catch'i gider, css-interop sessizce bozulur; doğrulama bu ikisine bakmaktır.
- **`postinstall: patch-package` adımını atlama** (`npm ci`/`npm install` çalıştırır).

## Expo SDK yükseltmesi (54 → 57, issue #284)
- **Yükseltmeyi TEMİZ kurulumda doğrula: `rm -rf node_modules && npx -y npm@10 ci && npm run verify`.** Eski `node_modules` kırıkları gizler; temiz kurulumda çıkanlar: (a) SDK 57'de `expo-modules-core` köke kaldırılmıyor → `package.json`'a açık bağımlılık (`~57.0.22`, bundledNativeModules sürümü), yoksa `modules/*/src` typecheck'te bulunamaz; (b) expo-audio 57'de `AudioPlayer.release()` kalktı → `remove()` (mock da).
- **Hedef seçimi:** npm `latest` = en güncel kararlı SDK (`next` = beta). Sürümler `node_modules/expo/bundledNativeModules.json` + `react-native/gradle/libs.versions.toml`'dan (SDK 57: RN 0.86.3, React 19.2.3, compileSdk/targetSdk 36, AGP 8.12.0, Kotlin 2.1.20, Gradle 9.3.1, iOS 16.4, TS 6.0). Native şablon farkı: `npm pack expo@<sürüm>` içindeki `template.tgz`'i eskisiyle `diff -ru`.
- **`expo prebuild` SDK 57'den beri native dizini varsayılan olarak SİLİP yeniden üretir → yalnız `-p ios --no-clean`, sonra `ios/`'u sil; `-p` vermeden ASLA.** `android/` git'te elle bakılıyor (widget, alarm, AppFunctions, `tools:node="remove"` izinleri, yön kilidi); Android şablon farkları elle uygulanır.
- **`npx expo install` (ve `--fix`) `app.json > plugins`'e kendiliğinden eklenti yazar** (datetimepicker, secure-store, sharing, web-browser, expo-font, expo-asset; secure-store iOS'a İngilizce Face ID metni ekler). Her seferinde `git diff app.json`, istenmeyeni at (eas-cli tuzağının ikizi).
- **Kök `splash` alanı SDK 55'te kalktı; SDK 57 prebuild'i onu sessizce yok sayar → `expo-splash-screen` eklentisi.** Paket yalnız iOS'ta bağlanır (`package.json > expo.autolinking.android.exclude`), çünkü Android teması `Theme.SplashScreen` türevi değil. Doğrulama: `npx expo-modules-autolinking resolve -p android --json`.
- **`android/agp-init.gradle` AGP'yi zorla sabitler** (`gradlew` `--init-script` ile enjekte eder); sürüm RN'in `agp`'siyle aynı olmalı (8.12.0). Wrapper'ı yenilerken `gradlew`'deki enjeksiyon bloğunu koru.
- **`MainApplication`: `ReactNativeHost` kalktı** → `ExpoReactHostFactory.getDefaultReactHost(context, packageList)`; elle eklenen paketler (`PlayStoreGuncelleme`, `WidgetVeri`, `WearSenkron`, `MuhafizAlarm`) listede kalmalı. `ReactApplication.reactNativeHost` artık fırlatır → native kodda `reactHost?.currentReactContext`. `hermesCommand` `hermes-compiler` paketinden (Hermes v1).
- **Ana iOS hedefine kopyalanan Swift dosyaları yerel pod'ları `internal import` ile almalı** (`siri-kisayollari`, `muhafiz-alarmkit`, `widget/ortak` → `internal import ExpoSiriKisayollari` / `ExpoMuhafizAlarmKit`). SDK 57'nin `ExpoModulesProvider.swift`'i `internal import X` yazar; aynı hedefte düz `import X` `ambiguous implicit access level for import` HATASIDIR (exit 65). Yalnız macOS CI'da görünür.
- **iOS dağıtım hedefi 16.4 (SDK 56'dan beri):** yerel modül podspec'leri `s.platforms = { :ios => '16.4' }`.
- **UIScene (iOS 27/Xcode 27'de zorunlu) henüz AÇILMADI.** SDK 57'de opt-in (`expo-build-properties > ios.enableSceneSupport`, expo ≥57.0.23), SDK 58'de varsayılan; cihazda doğrulanmadan derin bağlantı/bildirim yaşam döngüsü değişmesin. EAS'in SDK 57 imajı Xcode 26 olduğu için bugün gerekmez.
- **TypeScript 6:** `types` varsayılanı boş → `tsconfig.json > types: ["jest","node"]`; `noUncheckedSideEffectImports` açık → `import './global.css'` için `stil-modulleri.d.ts`; `jest.setup*.js` tsconfig'ten hariç (worklets kaynakları tür denetimine giriyordu).
- **Jest:** preset `@react-native/jest-preset` (açık devDependency); Reanimated 4.5 mock'u bile native worklets girişini yükler → `jest.setup.js`'te `jest.mock('react-native-worklets', () => require('react-native-worklets/src/mock'))`.
- **`expo-calendar` 57 kök girişi eski fonksiyonları ÇALIŞMA ANINDA fırlatır (`build/legacyWarnings.js`) → eski API yalnız `expo-calendar/legacy`'den.** Typecheck ve jest mock'ları yakalamaz; sahada (v0.31.0) takvim izni "verilmedi" görünüyordu. Nöbetçi: `expoCalendarLegacy.test.ts`. Yükseltmede her expo paketinde `legacyWarnings`/"will throw in runtime" ara.
- **`expo-file-system/next` alt yolu kalktı** → modern API kökten (`'expo-file-system'`), eski API `'expo-file-system/legacy'`; SDK 56'dan beri `File/Directory.copy()/move()` Promise döner.
- **Kullanılmayan native bağımlılığı yükseltmeye taşıma** (ör. `react-native-worklets-core` kaldırıldı); her native paket yeni RN'de ayrı derleme riskidir.
- **`react-native-pager-view` 8 iOS'ta SwiftUI'ye yeniden yazıldı** (API aynı, çok sayfa atlamada animasyon farklı) — AnaSayfa pager'ı iOS'ta cihazda bakılmalı. `expo-doctor`'ın "unmaintained @notifee" uyarısı bilinir; notifee bridgeless yolu (`HeadlessTask.getReactHost`) RN 0.86'da geçerli.
- **SDK yükseltmesinde dependabot ignore listesini yeniden üret** (bkz. [ci-ve-yayin.md](ci-ve-yayin.md)).
